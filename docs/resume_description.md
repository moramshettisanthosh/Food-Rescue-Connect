## High-Impact Project Description

**RescueConnect | Smart AI Food Rescue & Zero-Waste Ecosystem**  
*Full-Stack & Systems Developer* | *TypeScript, React, Node.js, PostgreSQL, Redis, Canvas, Docker*

*   Designed and engineered a full-scale Food Rescue web platform linking commercial caterers, canteens, and households with verified NGO shelters using smart proximity mapping and AI quality scans.
*   Built a highly interactive, responsive dashboard using **TypeScript** and **React** with a premium **dark-glassmorphism** aesthetic, featuring custom global translation routing and WCAG AA accessibility frameworks.
*   Developed a **custom topological map engine on HTML Canvas**, rendering coordinate networks, path routes, and animating volunteer riders in real-time, removing dependencies on heavy external mapping APIs.
*   Structured a professional **relational database schema in PostgreSQL** using spatial coordinates indexing, foreign key checks, and built automated database triggers in PL/pgSQL to manage gamification points and security audit logging.
*   Simulated a progressive ring notification escalator that prioritizes delivery targets based on spoilage index thresholds, reducing transit delays for perishable items.
*   Implemented a secure QR-code verification protocol at pickup points to prevent delivery abuse and maintain transaction integrity.
*   Authored clean **Docker configurations** and deployment files to support seamless static serving via optimized Nginx layers, integrated with **GitHub Actions CI/CD workflows**.
